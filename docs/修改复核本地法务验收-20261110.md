## 实际场景与结果

| 法务操作 | 实际结果 |
| --- | --- |
| 页面登录、填写我方身份和交易背景、上传 DOCX | 创建 v1，真实模型读完13段，只提出1项交付期限不明确问题 |
| 点击“认可意见”、填写理由 | 仅保存处理记录，文件仍为 v1，正文未改 |

| 切回 v1 | 原报告、原意见及法务修正记录仍在，历史版本无处理意见或确认结论入口 |
| 查看历史报告、导出 HTML | 保留逐项修改复核结果；页面未发生未处理异常 |

## 验收中修正的问题

- 既有流程脚本因页面同时存在多个“打开改稿”入口而定位不唯一，已限定到文档区域，16项流程回归通过。
- 新验收脚本的登录按钮、下拉框定位及模拟 DOCX 草稿缺少说明字段，调试后修正。这些是验收脚本问题，失败尝试不计为通过。
- 实际页面在确认法务结论后，顶部仍显示“等待法务判断”。已修正为在查看当前已确认报告时显示“法务结论已确认”，并通过重新构建和独立浏览器页面核对。三轮真实模型流程在此文案修正前完成；此后仅复查页面展示，没有重复调用模型。
