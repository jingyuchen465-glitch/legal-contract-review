## 新流程的使用位置

1. **提交合同**：选择合同类型后，查看“将匹配的正式检查”；选择我方为甲方／乙方；在“交易目的 / 重点检查项”填写交易背景及额外关注点。
2. **上传修改版本**：详情页选择文件，自动保存新版本并发起二次预审；任务进度在页面上方显示。
3. **关联主合同或模板**：详情页选择“关联主合同 / 模板并重新预审”。在“分类与业务背景 → 本次关联材料”取消不适用的旧材料，保存后生成新预审。新增材料会重新打开法务复核，已有结论保留在历史记录中；上传已签署件仅作归档文件。
4. **阅读与处理意见**：对应条款旁查看建议；完全重复的意见只显示一次，展开可查看涉及的检查项。采纳、修正、驳回会同时处理这一组；不同原文或不同处理状态不会合并。在线编辑时点击意见标题或“定位原文”，高亮条款并以绿色折线连接选中意见；多处引用可点“下一处”。
5. **修改正文并保存**：在线编辑需配置 OnlyOffice；也可下载 Word 本地修改后上传。法务采纳仅记录处理意见，正文修改需落实到文件。含旧解析缓存的 Word 会在新预审中用新版解析器重新识别。
6. **下载文件**：原件是所选上传文件；批注版在该预审文件上添加建议；报告独立展示检查结果；确认稿是法务确认同意的文件。PDF 的“可编辑 Word”属于文字重建稿，修改后须重新上传。
