# PDF 转 Word 改造与验收

## 运行方式

迁移 `013_pdf_word.js` 后，设置 `PDF_WORD_ENABLED=true`，重启 API 和 Worker。默认关闭。
转换服务需安装 `converter/requirements.txt` 并部署 `pdf_word.py`；`GET /pdf/health` 实际初始化 PDF 渲染和 Word 写入组件。沿用内部转换服务鉴权，不把模型凭据交给 Python 或浏览器。

复用系统当前中转站模型的地址和加密密钥。当前配置变化会使未完成的旧配置任务报错；重新生成创建独立缓存。扫描件/混合页在预审解析时调用视觉识别；原生纯文字 PDF 使用原解析器。Word 按按钮生成。

## 数据与接口

- `la_pdf_extractions` 固定源版本、哈希、引擎版本和模型配置签名，保存独立解析快照。
- `la_pdf_pages` 持久化成功页面结构、存疑项和用量；识别重试复用成功页面。
- `la_word_conversions` 管理排队、识别、排版、核验、完成、需核对及失败，产物与原 `version.conversion` 隔离。
- 新任务通过事务 Outbox 与 `pdf-word` 队列执行，数据库会话锁防止重复处理；Worker 启动恢复未完成任务。
- 接口见 OpenAPI 中 `word-conversions`、`word-conversion-capabilities` 和 `versions/from-conversion`。下载接口检查源合同权限，不暴露存储路径或凭据。

正文和表格生成原生 OOXML；图片、签章使用源页裁剪图并按页绝对位置放置。生成后 Python 比较写入文本，Node 再用实际 DOCX 解析器核对，LibreOffice 生成 PDF 对照稿，中转站对照原件和实际 Word 渲染列出差异。自动检查不能替代法务复核，结果默认标为“需核对”。

双栏正文使用可编辑的原生 Word 定位框保留各栏位置和 XML 阅读顺序，避免 LibreOffice 换栏段落行高造成右栏下移。单栏保留段落流和源页空白间距；字体替换、表格内边距及合并格文字对齐仍可能与原件不同，应对照核对。

创建编辑版本要求勾选已核对，并检查合同 revision 及当前源版本。该操作幂等，复用现有新增版本、重新预审和 OnlyOffice 修订保存；旧 PDF 审核意见不直接移植到 Word 段落。下载不改变合同当前版本或旧结论。

## 限制与回退

文件 50MB、100 页、单页渲染 1600 万像素、单个页面图像约 21MB 上限、转换与视觉并发各 1；单次视觉请求 120 秒，任务 60 分钟。网络、408、429、5xx 最多重试两次，遵守 Retry-After，超出任务时限停止。无可编辑正文、单元格越界/重复/缺失、写入内容不一致、截断、损坏/加密文件均不能报成功。

原生 PDF 图片区域包括签章时会触发混合页识别，调用次数通常为每页转录与文字复核各一次，加上 Word 生成后的逐页视觉对照；用量保存在页面记录。仅识别某页失败时重试该页；排版失败会复用全部识别页。

Worker 输出不含正文或凭据的 `service=pdf-word` 结构化完成/失败日志；核验报告保存识别与对照请求数、网络重试次数、模型返回的总 Token、问题页数及耗时，可据任务状态统计产物生成率及问题页比例。Token 未由中转站返回时不推算费用；失败请求的实际消耗仍以中转站账单为准。

关闭功能开关后拒绝创建和重试新转换任务；已生成副本仍可查看下载，业务原件和历史记录保留。临时排版目录由任务退出自动清理；长期产物进入现有对象存储及备份体系。

历史 PDF 已保存的解析缓存和审核依据不会自动改写。历史 PDF 可通过独立转换生成当前识别副本，核对后创建 Word 新版本并重新预审。原 PDF 旧解析和旧结论继续保留。

## 发布门槛

先运行 `npm test`、`npm run test:integration`、`python -m unittest converter/test_pdf_word.py` 和前端构建。新增集成测试覆盖断点恢复、去重、模型配置变更、跨合同权限、明确核对、幂等创建版本、源版本过期以及停用后保留下载。

真实模型验收使用虚构/脱敏的原生、扫描、中英混排、混合页、表格和签章样本。原始报错合同另行验收；缺少样本时不得标为已修复。实际 Word 与 PDF 必须逐页检查漏页漏条款、重复、金额主体日期、表格归属、裁切遮挡及可编辑性。OnlyOffice 打开、实际修订保存及新版本审核需要单独闭环验证。

生产开放前必须确认至少 10GB 可用空间。仅在依赖健康、模型验收、回归和容量门槛满足后灰度开放；未满足时保留默认关闭，不能宣称已上线可用。

## 本次验收记录

使用虚构合同在隔离数据库调用真实中转站 `gpt-6.1-sol`。样本包括原生中英表格及签章、扫描版本、同页原生与扫描混合、多页合并表格与横向双栏。除比较金额、日期、主体和 DOCX 再解析内容外，多页样本直接读取实际 Word 渲染后的文字坐标，要求左右栏起始位置对齐，检查纵向合并单元格仍为原生 OOXML。

实际浏览器验收覆盖转换副本下载、原件与预览并排查看、核对确认、新版本创建、真实 OnlyOffice 打开和修订保存。保存文件回读确认实际写入后，真实模型预分析和所选规则预审完成；旧 PDF 和旧审核记录保留。该验证只使用虚构文件，未向模型额外发送生产合同。

真实复杂报错原件、倾斜模糊扫描、跨页大表格、旋转原生页面和百页长文档仍待对应样本验收，不属于本轮已通过样本。自动化脚本显示通过仅表示其断言通过；核验报告中字体、表格偏移等差异仍须人工判断，不能据此宣称完全保真。
