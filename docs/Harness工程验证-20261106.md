## 业务与可靠性覆盖

新集成测试覆盖上传即建会话、固定文件快照、关联材料与补充材料、长文本游标读取、跨文件引用、准确的原文定位及无效引用拒绝。搜索命中不算原文读取；完整读取也不代表风险全部识别。

必要问题会持久保存并释放 Worker，回答后在同一会话继续。覆盖重复回答幂等、重复任务出队、并发续审互斥、停止、异常中断恢复、已提交结果的无额外模型请求恢复、追问新增结果版本与已确认结果冻结。

实际官方子进程测试覆盖两次请求预算暂停、连续三次重复动作暂停、进行中的模型请求取消；恢复和压缩由官方 SDK 执行。任务达到限制时不标为完整完成。事务发出 pg-boss 消息但尚未标记 outbox 已发送时模拟中断，重启后仍保持幂等。

法务保存的改稿、明确反馈和采纳/驳回可产生有来源的新经验；AI 判断和普通对话不能自动成为长期经验。覆盖旧规则/技能/经验不加载、来源撤销停用经验、已引用结果标记受影响、来源处理失败保留重试入口。

保留能力回归包括转换、钉钉收件及附件幂等、联合材料分组、OnlyOffice 保存和修订应用、PDF 转 Word、鉴权/CSRF、Socket 订阅权限、历史读取与导出。备份测试实际执行数据库备份及隔离恢复，并核对 Harness 日志和结果。外部转换、钉钉、Office 等服务在此类测试中使用受控替身，不等于完成各真实服务部署验收。

浏览器用例覆盖登录、上传自动打开工作台、必要问题及继续、证据定位、无需逐项处理即可整体确认、历史结果、新经验、运行设置保存，以及人工风险/证据/修改意见标注和评测保存。模拟结果在评测中明确标为工程模拟。

## 真实网关验证

使用现有保存的 `/chat/completions` 配置只读取得网关设置；审查写入使用临时独立数据库，结束后删除，不向现有业务库写入审查记录。API 密钥未写入验证报告，也不传给 Harness 子进程。

官方 SDK 工具探针实际发出两次模型 HTTP 请求，执行工具并核对随机值，后续模型正确接收工具结果。所用配置未返回推理内容；不能据此声称所有推理字段和模式均已验证。

`node scripts/agent-real-smoke.cjs` 使用虚构采购合同完成审查：

| 项目 | 观察结果 |
|---|---|
| 状态 | `completed` |
| 审查意见 | 6 条 |
| 实际模型 HTTP 请求 | 9 次 |
| 记录的工具调用 | 10 次 |
| 原文读取 | 8/8 块 |
| 耗时 | 134,109 ms |

实际调用包含材料目录、全文读取、任务笔记、新经验检索、内部法律检索和正文读取、官方检索入口、官方正文读取及结果提交。Brave 密钥未配置，官网正文请求失败；限制保留为无法完成的核实事项，不能将搜索摘要当成法律依据。结构化摘要保存于 `.local/agent-real-smoke-result.json`。此虚构样本没有法务独立标注，不能计算准确率、高风险召回率或证明风险全部识别。

此次本机真实网关运行曾出现流式回传的 `MaxListenersExceededWarning`。随后已修复 drain/close 监听器的相互清理，最终集成回归通过。后续服务器以真实网关完成完整审查，见上线记录。
