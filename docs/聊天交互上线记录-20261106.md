## 发布内容

聊天区采用 MUI X Chat 风格的左右消息布局，提供头像、时间、复制、审查等待状态、材料入口及键盘发送。继续使用现有 Vue 应用和业务接口，没有增加 React/MUI 依赖。

Agent 缺少影响判断的信息时，优先生成结构化问题，在输入区显示 Harness 式问题卡片，支持逐题单选、多选和“其他”填写。选项不预选，点击“确认并继续”后才提交。后端校验当前问题、选项归属及答案完整性，并保存结构化答案和可读正文。普通问题回答不自动作为法务经验学习。

已有文字问题和历史对话保留原记录，不根据旧文字猜测或补造选项。新卡片在后续 Agent 生成结构化待答问题时出现。刷新页面即可加载新聊天样式。
