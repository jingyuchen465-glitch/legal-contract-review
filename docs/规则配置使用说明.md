# 规则配置使用说明

打开工作台左侧「分类与规则中心」，或访问 http://localhost:8080/#/rules 。法务使用自己的系统管理员账号，即可新建、编辑、提交、评测和发布。

## 修改已有示例

1. 找到适用的规则包，例如「软件开发、许可与维护专项」，点击「编辑草稿」。
2. 基本信息中填写中文名称，选择「按合同类型」，勾选需要适用的合同类型。编号由系统管理，无须输入英文标识或 JSON。
3. 点击顶部「检查项」快速定位；逐项调整名称、风险等级和审查标准，按需新增或删除。
4. 参考资料为选填。添加后必须完整填写名称、准确内容、可追溯来源及生效日期；没有可靠来源时不要编造。
5. 点击「保存草稿」。编辑草稿会更新该草稿；修改正式版本会创建新草稿，保留原版本。保存本身不会使规则生效。
6. 在列表点击「提交审核」，核对摘要后确认。审核人员可用「查看内容」逐条核实，再点击「审核并发布」，确认范围和替换说明后发布。

同一个管理员账号可以执行这些步骤，发布表示法务已经确认标准。系统不会自动批准示例规则。

## 填写一条检查项

- 检查项名称：付款条件与验收挂钩。
- 风险等级：根据公司标准选择高、中或低风险。
- 审查标准示例：核查尾款是否以书面验收通过为前提。验收通过后 30 日内付款属于正常约定；未约定验收条件时提示风险；无法确定验收标准时标记需人工确认。
- 必检项：每次适用预审都应明确报告检查结果，包括无法判断的情况。
- 附加标签：标注检查主题；不会单独改变本规则包的适用范围。输入后可按回车、点添加或离开输入框完成添加。

以上文字仅示范填写方式，不代表已经通过公司法务审核的正式标准。

## 适用范围与生效

| 适用方式 | 用途 |
|---|---|
| 全部合同 | 对所有类型叠加通用检查 |
| 按合同大类 | 对选中的一级分类叠加检查 |
| 按合同类型 | 对选中的具体类型执行专项检查；启用正式预审需要这类已发布规则 |
| 按专项标签 | 合同包含任一所选标签时加载检查 |
| 模板对照 | 对选中类型执行写入检查项的模板要求，作为专项规则的补充 |

列表默认展示每个规则包的最新版本，同时提示当前正在生效的版本。勾选「显示历史版本」可查看、筛选以前的草稿、发布和停用版本。「查看内容」默认显示中文检查清单，维护用技术信息收起显示。

新版本发布会停用同一规则包原来的生效版本，只影响后续新建的预审。已经生成的报告不会随之变化，需要回到合同详情重新执行正式预审才能使用新规则。示例试审使用内置固定参考规则，不会使用正在编辑的草稿。

关闭编辑器或离开页面时，系统会提醒未保存的修改；网络请求失败时显示错误并保留表单。停用前会说明影响范围，若停用某类型唯一的专项规则，该类型将无法正式预审。
