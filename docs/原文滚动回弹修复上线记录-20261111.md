# 原文滚动回弹修复

2026-11-11 09:08:25（北京时间）发布至 https://legal.bi.youmeibi.com 。本次仅更新前端，API/Worker 进程保持原 PID，无数据库迁移、生产配置变更或合同写入。

## 原因与修复

用户点击审查意见定位原文后，再手动滚动左侧阅读器，会被约3秒一次的后台轮询拉回旧引用位置。`DocumentView.vue` 的定位监听器原先从一个 getter 返回新数组；轮询替换 `version/parsed` 对象时，虽然版本 ID、段落数量、已选意见和定位请求均未改变，新数组仍触发监听回调，重复执行平滑滚动。

改为 Vue 多来源监听，逐项比较实际定位输入。等价数据刷新不再重放旧定位，选中标记保留；主动再次点击同一意见、新引用、跨文件挂载及 PDF 加载完成后的定位仍然生效。

- 修复前在本地虚构合同及正式原合同只读页面均复现：两轮后台刷新重复调用了2次自动滚动，手动阅读位置被重置。
- 修复后本地真实 Edge 浏览器19项检查通过，包含实际鼠标滚轮、原生滚动条拖动、各自跨两次轮询保持位置、重复引用、标题、键盘、跨材料、历史报告、PDF 异步加载和手机定位。测试开启原生滚动条，并断言拖动确实改变阅读位置。
- 修改复核界面6项检查通过；前端构建、脚本语法及差异格式检查通过。
- 发布后正式原合同页面8项检查通过，包括滚轮和拖动分别跨两次轮询位置保持，以及重复引用、另一引用、标题、重复标题和手机定位。公网30个新资源 SHA256 一致，页面未处理异常为0。
