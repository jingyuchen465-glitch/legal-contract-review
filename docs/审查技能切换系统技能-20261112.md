# 审查技能切换系统技能

法务经验的“审查技能”卡片及知识详情增加“设为系统技能”。仅已审核、生效且没有待处理草稿的方法可以提升；确认后移入“系统技能”，可继续编辑、审核、停用、删除，也可以“切回审查技能”。项目内置系统技能仍为只读。

切换保留同一知识身份、部门、适用条件、来源、正文和正式版本，递增并发修订号并记录操作人、分类前后状态及时间。系统方法编辑后仍须审核。案例经验不能直接提升，未审核草稿不能绕过审核。来源撤销后停止复用。

新审查和继续审查从同部门生效知识建立快照，将提升的方法与内置技能一起预加载、写入加载记录，并在每次模型请求中注入全文。加载后的方法仅在合同满足适用条件时执行；条件不明确时标明待核实，不扩大部门或合同适用范围。快照固定正文和条件，历史记录不回写。

切换、切回、停用、删除或正式内容更新会使已引用该知识的审查标记待复核。继续新一轮时清除旧运行时上下文，按最新分类重建必读技能目录。迁移021仅新增默认false的is_system列及技能类型约束，已有知识分类保持原样。
