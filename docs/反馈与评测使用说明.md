# 法务反馈与规则维护

法务人员使用各自的系统管理员账号登录，所有账号均可查看全部合同、复核、修改规则和发布。部门只作备注。每人独立账号可以追溯实际操作者。

## 从审核结果改进规则

1. 在「合同与待办」打开合同审核详情，先采纳、驳回或修正 AI 的检查结论，并填写理由。
2. 点击「沉淀反馈案例」，选择误报、漏报或规则调整建议，说明正确判断及适用边界。
3. 点击「保存并修改规则」，或在「反馈与评测中心」点击「按反馈修改规则」。系统复制当前正式规则为草稿，打开并定位对应检查项，显示本次修改依据。
4. 如果无法定位原规则，系统要求人工选择目标规则包。不要随意选择无关规则包；没有适用的正式规则时先到规则中心配置。
5. 修改审查标准、风险等级、必检状态、标签或参考资料，保存草稿。草稿可以继续编辑；其他人已保存时会提示版本冲突，需刷新核对。
6. 可点击「试评测草稿」，优先使用规则调试集检查效果。
7. 返回规则中心，点击「提交审核」，核对后点击「审核并发布」，在确认框完成发布。

发布后，反馈自动显示「已发布」并关联正式版本。旧正式版本保留为历史版本。新标准仅影响发布后新建的预审任务，已排队任务和历史报告保留原依据；同一合同需要重新创建正式预审才能使用新标准。

如果其他人先发布了同一规则包的新版本，系统会拒绝发布基于旧版本的草稿。请核对最新正式内容，合并修改后重新创建草稿。

## 分类纠错与正常表达

- 分类纠错：点击「修改分类标准」，选择正确合同类型，编辑分类说明、适用条件、排除条件及示例。保存草稿并确认发布，后续新预审使用新分类指导；历史记录保留当时版本。
- 正常表达：点击「加入规则参考资料」，核实来源、内容和日期，按规则草稿流程保存并发布；也可直接保存为评测样本。
- 已无参考价值的反馈可以停用，来源记录仍然保留。

## 保存评测样本

在反馈中点击「保存为评测样本」。系统自动带入合同原文、人工确认的分类、专项标签、预期风险和高风险项。法务核实或补充标注，勾选确认后保存，无需填写 JSON。

被驳回的误报不会自动成为风险正例；人工新增风险须先成为可执行规则，再作为对应规则的风险正例。来源审核有未处理项时，页面提示逐项核实。重复保存同一反馈会返回已有样本。

规则调试集用于日常改进，可选择某个规则草稿进行评测；独立验收集用于最终验证，仅使用正式规则。评测本身不会发布规则，指标也不能代替法务确认。缺少高风险正例、样本执行失败或数据不足时，不能据此宣告质量达标。

“越用越聪明”依靠法务持续维护规则、分类指导、参考资料和评测样本。提交反馈不会自动训练模型，也不会立即替换正式规则。
