## 业务验收仍需要的输入

- 公司主体清单、交易立场定义和字段负责人。
- 采购及海外仓各至少 20 份代表性合同，包含正常、高风险、复杂表达和扫描件。
- 法务确认的分类、标签、风险与正常边界，以及独立验收集。
- 两类正式规则、参考模板、可追溯法律资料；示例草稿不能代替正式标准。
- 指定模型账号、服务、数据外发范围和实际成本口径。
- 钉钉内部应用、审批/附件权限、模板标识、法务节点 ID 和附件字段映射。
- Docker / OCR / OnlyOffice / Milvus 运行环境，以及实际电脑性能基线。

## 质量目标

分类 ≥95%、高风险召回 ≥95%、风险精确率 ≥80%、已有条款原文引用可验证率 100%、结论版本绑定 100%。前四项中的模型能力必须由独立历史样本测量；工程引用验证和版本约束测试不能替代法律质量评测。

Jev 未实测，不宣称比默认模型更优；缺少正例的风险项不宣告通过；不把一类合同的结果推广为其他合同类型或全部境外法问题已覆盖。
