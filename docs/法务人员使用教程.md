# 法律 Agent 合同预审工作台｜法务简明教程

## 当前使用方式

页面结构和功能延续现有线上版本：从「合同与待办」提交合同，后台预分析后确认主体、审查范围和核心目的，再在审查详情中核对原文、批注和风险，完成复核、修改重审、确认结论及归档。白底、黑灰层次和蓝色按钮采用参考项目的视觉风格。

**无需维护、审核或发布规则包。** 全部合同类型会自动加载内置审查要点；之前配置的公司专项标准仍优先适用。原有版本切换、批注、钉钉收件、反馈评测和合同经验功能保留。

模型连接在「接入与模型配置」设置；在线编辑需要配置并启动 OnlyOffice。此前上传的合同继续在「合同与待办」访问。

历史上因缺少规则而暂停的任务，点击「重新预审」即可使用当前审查要点生成新记录，无需修改旧记录。

适用于日常合同预审和复核。**AI 预审完成不等于法务同意，最终结论由法务确认。**

日常流程：**提交合同 → 后台预分析 → 选择主体、模板、审查点和核心目的 → 开始分析 → 逐项复核 → 修改重审 → 确认结论 → 回传归档**。

## 1. 登录并接收合同

使用个人账号登录管理员提供的工作台地址。本机访问地址为 [http://localhost:8080](http://localhost:8080)；其他电脑使用管理员提供的访问地址。

- **手动提交**：进入“合同与待办”，点击“＋ 提交合同”，选择 **PDF、Word、Excel、CSV、PPT 或 ODF（每份不超过50MB）**，点击“提交并预分析”。合同类型、主体及交易目的可以先留空，稍后由 AI 识别并由你确认。多个文件各建一个任务；预分析时可以离开页面，继续处理其他合同。
- **钉钉收件（如已启用）**：进入“钉钉收件”，点击“绑定钉钉账号”完成授权。审批分配给本人后，系统收取审批中支持的 PDF、Word、Excel、CSV、PPT 及 ODF 文件，随后在“合同与待办”打开处理。绑定前的历史审批不会自动全量补齐。

业务信息示例：我方主体填写公司全称；立场填写“采购方”；交易目的填写“采购合同管理软件，重点关注验收、数据保密和退出交接”。

## 2. 预分析后确认审查信息

点击台账中的合同查看后台进度；离开、刷新或重新进入页面后继续显示同一任务。预分析完成不会自动进行完整审查，请依次确认：

1. 查看 AI 初步识别的合同名称，需要时展开合同预览对照原件。
2. 选择审查立场。下拉框显示具体签约主体全名及交易角色，例如“甲方：某某公司（服务购买方/退款收款方）”；识别遗漏时手动补充主体和角色。
3. 选择合同分类和审查模板，按需勾选检查项。默认全选模板事项及本合同特有的 AI 建议，可取消不需要的项目。
4. 编辑、删除或添加审查核心目的；有效选择自动保存。
5. 法务点击“开始分析”，系统才启动完整审查。正式审查仍在后台进行，期间可处理其他合同。

这些操作替代日常手动维护规则包，不要求先发布规则。确认后的主体、模板、审查点和目的固定在本次任务里，重试及历史记录不受后续编辑影响。旧报告保留原复核方式，需要重新审查时点击“重新预审”进入新的预分析确认流程。

## 3. 阅读原文，逐条复核

等待显示“AI 预审完成”后开始复核：

1. 在左侧“审查清单”选择检查项，可筛选“未处理”或“高风险”。
2. 在合同原文旁查看批注；点击清单、原文标记或批注编号，可以定位对应条款。
3. 按需打开意见详情，核对原文证据、AI 判断、规则与法律依据及修改建议。缺失条款和无法定位的意见在全文末尾查看。
4. 逐项保存法务处理意见。

阅读区可切换“原文旁批”“彩色标记”“仅原文”；清单可收起，便于阅读全文。

| 法务处理选项 | 使用场景 |
|---|---|
| 采纳 | 认可 AI 的判断及建议 |
| 驳回 | 属于误报，结合上下文后不构成问题 |
| 已修正 | 需要调整风险等级、理由或修改建议 |
| 待补充 | 需业务补充事实或材料，尚不能作出判断 |
| 已确认处理意见 | 已人工核实并明确处理方式，填写理由留痕 |

需要调整时，打开“条款意见与法务复核”，填写处理理由、风险等级或修正建议，点击“保存复核意见”。发现漏审风险，可在清单点击“＋ 补充”新增人工风险。

**采纳只记录法务处理意见，不会自动修改合同正文。** “待补充”仍属于未处理事项，补齐信息并作出判断后才能确认最终结论。

## 4. 修改合同并重新审查

- **本机修改**：下载原件，在 Word 修改并保存；回到同一合同详情，选择“上传修改版本”→“选择文件”，上传修改稿。系统会建立新版本并后台预分析，完成后重新确认审查信息再开始分析。
- **从本机修改中整理经验**：完成新版本审查并确认最终结论后，后台会对照直接上一版正文，整理新增、删除及修改内容。旧稿无需先在系统逐条复核；在“合同经验整理 → 查看修改前后对比”核对两稿，再编辑、采纳提案并发布。未记录的修改原因仍需核实。请在同一合同内上传修改版本，以保留前后版本关系。
- **在线修改（编辑服务已接通时）**：DOCX 可点击“在线编辑”，有效保存后产生新版本，再确认审查范围并开始二次审查。编辑器不可用时，可用本机修改方式。
- **退回业务修改**：在意见详情中点击“退回修改 / 补件”，填写理由。退回后原预审冻结，收到修改稿后上传新版本继续处理。

补充材料和签署件请在详情中分别选择“上传补充材料”“上传已签署件”。上传这些附件不会代替正文修改或解除原预审冻结；新增事实需补入业务背景并重新预审。

可通过“预审记录”和“原文版本”查看历史；复核前确认当前文件与本次预审对应。

## 5. 确认最终结论

完成**正式预审**、确认本版本分类及立场，并处理全部风险和不确定项后，点击“确认最终结论”：

- **同意**：确认可按本次审核结果推进。
- **附条件同意**：写明必须落实的修改或审批条件。
- **不同意**：填写明确理由。

点击“确认并保存结论”。结论绑定当前文件版本和本次预审；后续修改稿需要重新审查。

## 6. 下载、回传和归档

1. 展开“下载与导出”，下载当前合同原件、独立审查报告；DOCX 还可下载批注合同或彩色建议稿。建议稿用于沟通修改意见，使用前需核对。
2. 按公司流程，**人工**把审核终稿及报告回传钉钉或其他审批渠道。系统不会代替本人同意或拒绝钉钉审批。
3. 点击“人工回传与归档”，记录实际回传情况和备注；已有签署件时上传并关联。尚未签署时可后续补齐。

“已归档”表示系统归档记录已保存，不代表合同已经线下签署。按分类自动复制文件到目录是另一项配置，也不等于完成法务审核归档。

## 7. 常见问题速查

| 页面情况 | 怎么处理 |
|---|---|
| 排队中 / 处理中 | 等待结果，耗时受合同长度、模型速度和网络影响 |
| 待补充 / 人工处理 | 查看提示：补背景、确认分类，或请管理员处理模型、OCR、规则等问题 |
| 待处理 0 项，但不能确认结论 | 核对是否完成正式预审、分类与立场是否确认；示例试审不能确认结论 |
| 扫描件无法识别 | 联系管理员检查 OCR；旧 DOC、表格和演示文稿由系统自动转换，失败可重试 |
| 意见判断不准确 | 先驳回或修正并留理由，再用“沉淀反馈案例”保存误报、漏报或规则建议 |
| 规则发布后结果没变化 | 新规则用于后续新建预审；回到合同详情点击“正式重新预审” |
| 页面报错或处理失败 | 记录合同编号、版本和错误提示，联系管理员 |

复核结束前，确认三件事：**审核的是当前版本、所有待处理项已有明确意见、回传的终稿与最终结论对应。**
