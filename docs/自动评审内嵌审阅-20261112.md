# 自动评审直接打开页边审阅

2026-11-12 本地实现。尚未发布到线上环境。

自动评审批次详情现在提供“打开合同审阅”入口，每份已生成的 DOCX 修订稿在“报告与改稿”中提供“在程序中审阅”。点击后直接进入现有的合同正文、页边批注和原生 Word 修订工作区。下载入口继续提供。

入口为 `/#/auto-review/:id/artifacts/:artifactId`，刷新可重新打开同一文件。法务处理批注、接受或拒绝修订、编辑后可保存；保存并返回会回到原批次。再次进入时恢复这份修订稿之后保存的当前版本。

自动修订稿原来是原合同的独立不可变分支，并不是合同的当前版本。本次允许首次人工保存基于当前批次的修订稿创建新版本，要求其对应原件仍是当前合同版本、产物属于本次报告且批次已经完成或部分完成。新版本的父版本记录为自动修订稿。后续并发旧版本保存仍返回 409；原件及自动修订产物均保留。读取和保存继续使用原有身份、合同访问和法务角色校验。

非可编辑角色、历史报告以及原合同已被其他新稿替换的产物只能只读审阅和导出。尚未成功生成 DOCX 的材料继续显示已有生成状态和报告，不提供无效的审阅入口。
